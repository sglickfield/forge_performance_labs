# Loom — 5 minutes, second take

Do not produce seven takes. Walk it once, record the second.

## Clock

**0:00–0:25 — the problem**
Monday morning. Twelve athletes tested last week. A real letter takes 30–45 minutes. Most of them get a CSV or nothing. Open the empty desk.

**0:25–0:55 — load the week**
Click "Load this week's combine." Roster appears. Point at Casey (skipped jumps), Taylor (wrist + wild balance split), Sam (3.92s sprint — verify). The desk already knows who is messy.

**0:55–2:10 — the wow**
Open one clean athlete (Maya or Aisha) *and* one messy one (Casey or Taylor). Generate. Show:

- scores against the 2019 handbook, not a mystery score
- the letter in the coach's voice
- edit the section on the right, type your name, sign at the bottom
- copy the athlete link — they see only their letter, no desk
- flip to Print / PDF if you want a paper copy

**2:10–3:00 — new file**
Drop a JSON (or re-drop one). This is the live-session requirement. The desk accepts it while running.

**3:00–4:20 — why the AI is built this way**
Facts first. Schema. Fact-check. Golden test for Casey. If the key is missing, the same facts still write a draft. V-awesome: eval set of signed letters, prompt versions, "working" = the coach's edit distance over time.

**4:20–5:00 — what we cut**
No cloud, no history, no mid-thigh invented range, no auto-send. High-touch coach, ten clients, a letter they will sign.
