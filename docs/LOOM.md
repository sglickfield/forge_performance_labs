# Loom — 5 minutes, second take

Walk it once. Record the second take.

## Clock

**0:00–0:25 — the problem**
Monday morning. Twelve athletes tested last week. A real letter takes 30–45 minutes. Most of them get a CSV or nothing. Open the empty desk.

**0:25–0:55 — load the week**
Click "Load this week's combine." Roster appears with drafts already written. Point at Casey (skipped jumps), Taylor (wrist + wild balance split), Sam (3.92s sprint — verify). The desk already knows who is messy.

**0:55–2:10 — the wow**
Open one clean athlete (Maya or Aisha) *and* one messy one (Casey or Taylor). The letter is already there. Show:

- scores against the 2019 handbook
- the letter, edit rail on the right
- confidence vs the gold letter (or “no gold letter” if we don’t have one)
- type your name, sign, copy the athlete link — they see only their letter
- Print / PDF if you want paper
- Redraft only if you want to show live Grok

**2:10–3:00 — new file**
Drop a JSON. The desk saves it under that athlete and drafts it while the app is running.

**3:00–4:20 — why the AI is built this way**
Facts first. Schema. Fact-check. Casey cannot get jump scores. No API key → same facts, template writer. Confidence is closeness to gold, not a grade of the coaching.

**4:20–5:00 — what we cut**
No accounts, no email, no “my own voice,” no A/B prompts, no charts. High-touch coach, a letter they will sign.
